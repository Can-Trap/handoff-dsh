Handoff to DeepSeek Harness

Open Design → DeepSeek Harness. The open-source design-to-code handoff.

Open Design→ detect→ bundle→ validate→ archive→ DeepSeek Harness

Prompt-first

Emits the MCP prompt the agent pastes. The archive is the fallback, not the default.

Verbatim mirror

Nothing renamed or re-suffixed. Button.jsx stays Button.jsx.

Design system, whole

Canonical directory, the short alias the HTML actually loads, and real font binaries.

Fidelity you can lint

Generates an oxlint config that flags raw hex, raw px, off-system fonts and undeclared props.

Verified on arrival

The companion DSH bundle re-checks the archive's own bytes before it extracts any of them.
